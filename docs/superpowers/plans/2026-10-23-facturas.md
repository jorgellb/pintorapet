# Facturas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** cada pedido pagado genera una factura simplificada (o completa si la clienta da su NIF), con IVA por tipo, huella Veri\*factu encadenada y PDF descargable en el panel y en el estado del pedido.

**Architecture:** el IVA, la numeración y la huella viven en SQL (migración `20261025000000_invoices.sql`), igual que el envío. `issue_invoice` bloquea la serie y la cadena; un trigger la lanza cuando el pedido pasa a `paid` y nunca bloquea el cobro. Astro valida, sirve el PDF (`pdf-lib` + `qrcode`) y pinta la interfaz.

**Tech Stack:** Astro 7 SSR, Supabase (Postgres + pgcrypto en `extensions`), zod v4, vitest, pdf-lib, qrcode.

```ts
import { createHash } from 'node:crypto';

export type VerifactuKind = 'F1' | 'F2';

export type VerifactuInput = {
  issuerNif: string;
  number: string;
  issuedOn: string;
  kind: VerifactuKind;
  vatCents: number;
  totalCents: number;
  prevHash: string;
  generatedAt: string;
};

export function formatVerifactuAmount(cents: number): string {
  return (cents / 100).toFixed(2);
}

export function verifactuChain(input: VerifactuInput): string {
  return [
    `IDEmisorFactura=${input.issuerNif.trim()}`,
    `NumSerieFactura=${input.number.trim()}`,
    `FechaExpedicionFactura=${input.issuedOn.trim()}`,
    `TipoFactura=${input.kind}`,
    `CuotaTotal=${formatVerifactuAmount(input.vatCents)}`,
    `ImporteTotal=${formatVerifactuAmount(input.totalCents)}`,
    `Huella=${input.prevHash.trim()}`,
    `FechaHoraHusoGenRegistro=${input.generatedAt.trim()}`,
  ].join('&');
}

export function verifactuHash(input: VerifactuInput): string {
  return createHash('sha256').update(verifactuChain(input), 'utf8').digest('hex').toUpperCase();
}

export function verifactuQrUrl(input: {
  nif: string;
  number: string;
  date: string;
  totalCents: number;
}): string {
  const q = new URLSearchParams({
    nif: input.nif,
    numserie: input.number,
    fecha: input.date,
    importe: formatVerifactuAmount(input.totalCents),
  });
  return `https://www2.agenciatributaria.gob.es/wlpl/TIKE-CONT/ValidarQR?${q.toString()}`;
}
```

**2a. Product VAT and helpers**

```sql
ALTER TABLE public.products
  ADD COLUMN vat_rate numeric(4,2) NOT NULL DEFAULT 21
  CONSTRAINT products_vat_rate_ok CHECK (vat_rate IN (0, 4, 10, 21));

UPDATE public.products p
SET vat_rate = CASE c.code WHEN 'originals' THEN 10 ELSE 21 END
FROM public.categories c
WHERE c.id = p.category_id;

CREATE OR REPLACE FUNCTION public.products_default_vat()
RETURNS trigger
LANGUAGE plpgsql
SET search_path = pg_catalog, public
AS $$
BEGIN
  IF NEW.parent_id IS NOT NULL THEN
    SELECT vat_rate INTO NEW.vat_rate FROM public.products WHERE id = NEW.parent_id;
  ELSE
    SELECT CASE code WHEN 'originals' THEN 10 ELSE 21 END
      INTO NEW.vat_rate
    FROM public.categories WHERE id = NEW.category_id;
  END IF;
  NEW.vat_rate := coalesce(NEW.vat_rate, 21);
  RETURN NEW;
END;
$$;

CREATE TRIGGER products_default_vat
  BEFORE INSERT ON public.products
  FOR EACH ROW EXECUTE FUNCTION public.products_default_vat();

CREATE OR REPLACE FUNCTION public.net_cents(p_gross integer, p_rate numeric)
RETURNS integer
LANGUAGE sql IMMUTABLE
AS $$
  SELECT CASE WHEN p_rate = 0 THEN p_gross
              ELSE round(p_gross / (1 + p_rate / 100.0))::integer
         END;
$$;

CREATE OR REPLACE FUNCTION public.is_eu_country(p_country text)
RETURNS boolean
LANGUAGE sql IMMUTABLE
AS $$
  SELECT upper(p_country) IN (
    'AT','BE','BG','CY','CZ','DE','DK','EE','ES','FI','FR','GR','HR','HU',
    'IE','IT','LT','LU','LV','MT','NL','PL','PT','RO','SE','SI','SK'
  );
$$;

CREATE OR REPLACE FUNCTION public.vat_regime(p_country text, p_postal_code text)
RETURNS text
LANGUAGE sql IMMUTABLE
SET search_path = pg_catalog, public
AS $$
  SELECT CASE
    WHEN p_country IS NULL OR p_country !~* '^[A-Za-z]{2}$' THEN NULL
    WHEN upper(p_country) = 'ES'
         AND public.es_region(p_postal_code) IN ('canarias', 'ceuta', 'melilla')
      THEN 'no_vat'
    WHEN public.is_eu_country(p_country) THEN 'es_vat'
    ELSE 'no_vat'
  END;
$$;

CREATE OR REPLACE FUNCTION public.vat_exemption_note(
  p_regime text, p_country text, p_postal text, p_locale text
)
RETURNS text
LANGUAGE sql IMMUTABLE
SET search_path = pg_catalog, public
AS $$
  SELECT CASE
    WHEN p_regime IS DISTINCT FROM 'no_vat' THEN NULL
    WHEN upper(p_country) = 'ES' AND public.es_region(p_postal) = 'canarias'
      THEN CASE p_locale WHEN 'en' THEN 'Supply not subject to Spanish VAT (Canary Islands).'
                         ELSE 'Entrega no sujeta al IVA (Canarias).' END
    WHEN upper(p_country) = 'ES' AND public.es_region(p_postal) = 'ceuta'
      THEN CASE p_locale WHEN 'en' THEN 'Supply not subject to Spanish VAT (Ceuta).'
                         ELSE 'Entrega no sujeta al IVA (Ceuta).' END
    WHEN upper(p_country) = 'ES' AND public.es_region(p_postal) = 'melilla'
      THEN CASE p_locale WHEN 'en' THEN 'Supply not subject to Spanish VAT (Melilla).'
                         ELSE 'Entrega no sujeta al IVA (Melilla).' END
    ELSE CASE p_locale WHEN 'en' THEN 'Export exempt from VAT.'
                       ELSE 'Exportación exenta de IVA.' END
  END;
$$;
```

`issue_invoice(p_order_id uuid) RETURNS uuid`:

1. `SELECT * FROM orders WHERE id = p_order_id FOR UPDATE`. If missing → `ORDER_NOT_FOUND`. If `payment_status <> 'paid'` → `INVOICE_ORDER_NOT_PAID`.
2. If an invoice exists for that order, return its `id`.
3. If `NOT invoice_config_complete()` → `INVOICE_CONFIG_INCOMPLETE`.
4. `v_kind := CASE WHEN invoice_customer IS NOT NULL THEN 'full' ELSE 'simplified' END`.
5. Prefix from config (`fullPrefix` / `simplifiedPrefix`). Year = `extract(year from timezone('Europe/Madrid', now()))`.
6. `INSERT INTO invoice_series (code, year) VALUES (prefix, year) ON CONFLICT DO NOTHING;` then `SELECT next_number FROM invoice_series WHERE code = prefix AND year = year FOR UPDATE;` then increment.
7. `v_full := prefix || year || '-' || lpad(number::text, 4, '0')` → `S2026-0001`.
8. Lines: from `order_items` plus the matching quote line (`checkout_attempts` → `checkout_quotes.lines` by `sku`) for `vat_rate`. Charged total per line = `line_subtotal_cents`. Effective rate = `0` when `vat_regime = 'no_vat'`, else the line rate. `base = net_cents(total, rate)`, `vat = total - base`. Append a shipping line (`Envío` / `Shipping`) with `orders.shipping_cents` and `shipping_vat_rate` (0 when `no_vat`).
9. `breakdown` = aggregate by rate `{ "21": { "base": n, "vat": n }, ... }`.
10. `issuer` = snapshot of `invoice_config` name/nif/address/postal/city/kind. `customer` = `invoice_customer` when `full`.
11. `PERFORM pg_advisory_xact_lock(872023);` then `SELECT hash FROM invoices ORDER BY record_generated_at, id DESC LIMIT 1` → `prev_hash`.
12. `v_at := clock_timestamp();` local stamp:

```sql
v_local := timezone('Europe/Madrid', v_at);
v_utc := timezone('UTC', v_at);
v_off := v_local - v_utc;
v_stamp := to_char(v_local, 'YYYY-MM-DD"T"HH24:MI:SS')
        || CASE WHEN v_off >= interval '0' THEN '+' ELSE '-' END
        || to_char(abs(extract(epoch from v_off))::integer * interval '1 second', 'HH24:MI');
```

`issued_on` = `to_char(timezone('Europe/Madrid', v_at), 'DD-MM-YYYY')`.
13. `hash = verifactu_hash(issuerNif, full_number, issued_on, F1|F2, vat_cents, total_cents, prev, stamp)` where F1 = full, F2 = simplified.
14. `qr_url` with the same query as `verifactuQrUrl`.
15. Insert and return `id`.

}

export function invoiceConfigSchema() {
  return z.object({
    issuerName: z.string().trim().min(1).max(160),
    issuerNif: z.string().trim().min(8).max(20),
    issuerAddress: z.string().trim().min(1).max(200),
    issuerPostalCode: z.string().trim().min(1).max(12),
    issuerCity: z.string().trim().min(1).max(80),
    issuerKind: z.enum(['autonomo', 'sociedad']),
    simplifiedPrefix: z.string().regex(/^[A-Z]$/).default('S'),
    fullPrefix: z.string().regex(/^[A-Z]$/).default('F'),
    shippingVatRate: z.union([z.literal(21), z.literal(10), z.literal(4), z.literal(0)]),

  }).strict().superRefine((value, ctx) => {
    if (!isValidSpanishTaxId(value.issuerNif)) {
      ctx.addIssue({ code: 'custom', path: ['issuerNif'], message: 'INVALID_TAX_ID' });
    }
  });
}
